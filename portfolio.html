‘CPA’가 아닌 ‘지역 CAC’로 — 광고주를 설득해 예산을 키우다

글로벌랩스 · 2026.01~09 · 병원 2곳 전담(1곳 메인 대형 광고주) · 구글·메타·틱톡 / GA4
문제

리드는 쌓이는데 ‘CPA 단가’만 보면 진짜 효율이 안 보였다. 리드가 많아도 내원·매출로 이어지지 않으면 광고주에겐 의미가 없었다.

데이터 진단

리드 CPA가 아니라 지역별 내원율·CAC·ROAS로 성과를 봐야 진짜 효율이 보인다. 지역별로 내원율이 2~3배 차이났다.

제안·설득

‘지역 CAC’ 관점을 광고주에게 직접 제안 → 내원율 높은 지역으로 예산 재배분·증액을 설득(경기남부 30→45% 등). 신규 매체(틱톡) 주 타겟 규모를 확인해 직접 제안.

KB국민은행 · 신규 매체 발굴·제안

‘틱톡=10대’ 통념을 데이터로 뒤집고, 신규 매체를 제안

블루오렌지 · 2025.09~12 · KB 담당자 직접 소통 · 집행 약 8억
문제

10대(학생) 타겟 금융 브랜드 캠페인에서 기존 채널만으로는 학생 도달·효율에 한계가 있었다.

데이터 진단

‘틱톡=10대’ 통념과 달리 노출·조회의 69%가 45세+임을 실측. 미성년 타겟 인스타는 저효율.

제안·설득

연령 축소·학부모 관심사 재집중을 제안하고, 학생 타겟에 맞는 신규 매체(교육앱 콴다)를 직접 발굴·제안해 4→5채널로 확장.

콜 1차 컨택부터 계약 클로징까지 단독 완주

문제

월 1회 단체 창업설명회 구조라 고정일에 5명+ 모으기 어렵고, 참석·계약 전환이 저조했다.

진단

‘참석자 수를 늘린다’가 아니라 ‘전환되는 단계로 구조를 바꿔야 한다’ — 현장 체험이 신뢰·전환을 만든다는 가설.

실행

상시 1:1 실물 체험형 현장 상담으로 재설계. 콜 약 100건으로 니즈·예산을 등급화하고, 제안서 작성·피칭부터 계약 클로징까지 혼자 완주.

“할인은 비용이 아니라 점유율을 BEP 위로 올리는 투자”

공유창고(박스풀) · B2C 라커 점유율 연동 다이내믹 할인 쿠폰 · 약 10개 지점
문제

신규 지점은 라커 점유율 0에서 시작 — BEP 도달 전까지 공실이 곧 적자였다.

진단

점유율 50%=손익분기, 70%+면 임대료가 순수익. 라커 평균 이용 13개월이라 한 번 입주하면 거의 이탈하지 않는다.

설계

진입 허들만 낮추면 초기 할인은 정가 구독으로 회수 → 점유율 구간별 차등 할인 쿠폰(50%미만=3개월 50% / 70%+=30% / 90%+=정가).
